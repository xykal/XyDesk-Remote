# Audit: controls, FreeRDP, certificates, ports — 2026-09-29

**Product attribution:** XyVerse Technology Global

**Scope:** Reported failure of added HUD controls/mapping and layout reset; poor-network behavior; connection-time certificate decisions; port entry; remote drive label (`XyDesk`); and native queue hardening. Source audit started against `main` at `558d4ae` plus uncommitted draft diff `034b7f4`.

## Prioritized findings and fixes

1. **[CRIT] Added HUD keyboard and combo buttons sent raw Android `KeyEvent.KEYCODE_*` integers as Windows `VK_*` codes.** `SessionSurfaceController.kt:269` called `inputManager?.processVirtualKey(keyCode, down)`, which forwards directly to `LibFreeRDP.sendKeyEvent` (`android_freerdp.c:1068: GetVirtualScanCodeFromVirtualKeyCode(keycode, 4)`). Because `HudKeyCatalog` (`HudKey.kt:188-291`) stores Android `KEYCODE_*` constants, every added key/combo either sent the wrong key (`Enter`=66 -> `VK_KEY_B`, `Backspace`=67 -> `VK_KEY_C`, `Esc`=111 -> `VK_DIVIDE`, `Ctrl`=113 -> `VK_F2`, `Alt`=57 -> `VK_KEY_9`, `Win`=117 -> `VK_F6`) or produced scancode `0` (`Tab`, `Space`, `Shift`, `A-Z`, `Ctrl+C`, `Ctrl+V`). `KeyboardMapper.keymapAndroid` also lacked `CTRL_LEFT/RIGHT`, `SHIFT_LEFT/RIGHT`, `ALT_LEFT/RIGHT`, `META_LEFT/RIGHT`, and `MENU`. **Fix applied:** added `KeyboardMapper.translateAndroidKeyCode` and `SessionInputManager.sendAndroidKeyCode`, routed `SessionSurfaceController.sendVirtualKey` through it, rejected `scancode == 0` in `android_freerdp.c`, and added JVM unit tests covering 100% of `HudKeyCatalog` keys and combos.
2. **[HIGH] HUD layout reset when dragging multiple buttons, and 8 px (~2 dp) movement threshold dropped taps.** `SessionKeyLayer.kt:101-237` captured `onDrag`, `onPhase`, and `onEdit` inside a non-restarting `pointerInput` block without `rememberUpdatedState`; dragging a second button invoked a stale `onMove` closure that overwrote previously moved buttons back to their old positions. In addition, `travelled > 8f` raw pixels (~2 dp) set `dragged = true` even in normal use mode (`mappingMode == false`), cancelling taps on `COMBO`, `TOGGLE`, `SCROLL_UP/DOWN`, and `INPUT_SWITCH` controls whenever a thumb wobbled, and preventing taps from opening `HudKeyEditor` in layout mode. **Fix applied:** wrapped callbacks/bounds in `rememberUpdatedState`, keyed each button by `key.id`, gated drag/scroll gesture start via `shouldStartHudButtonGesture` using `viewConfiguration.touchSlop` only for `mappingMode` or `SCROLL_SLIDER`, and set `defaultAction` (`TOGGLE` for standalone modifiers, `HOLD` for hold-drag click).
3. **[HIGH] Native input dequeue was O(n) per event and HUD cursor state desynced in direct-touch mode.** `android_event.c:28-90` shifted the entire array via `memmove` on every pop and lacked teardown guards inside the lock; in `XyDeskSession.kt:570-605`, direct touch (`SessionView`) did not update `cursorX`/`cursorY`, so HUD clicks/scrolls acted at the screen center, and `boundInstance != 0L` could block cursor dispatch before `LaunchedEffect` bound the instance. **Fix applied:** O(1) circular queue with adjacent pure `PTR_FLAGS_MOVE` coalescing and teardown guards, immediate `inputManager.attachSession` on `bind`, cursor-position sync from `SessionInputManager` to `XyDeskSession`, and throttled content-free failure notices.
4. **[MED] Poor-network tuning and certificate UI.** `RdpOptions.kt:47-55` and `RdpUri.kt:57-72` lacked an opt-in low-bandwidth profile; `XyDeskSession.kt:1542-1620` and `Screens.kt:666-710` expanded certificate details and saved fingerprints by default. **Fix applied:** opt-in `lowBandwidth` (`broadband-low` + `AVC420` when H.264 is enabled), collapsible certificate details and trusted list, and "Tolak kali ini" / "Deny this time".
5. **[LOW] Single-field `host[:port]` address input and `XyDesk` remote drive label.** `AddDeviceScreen.kt:75-220` and `RdpUri.kt:21-65` split host and port and labeled the redirected folder `sdcard`. **Fix applied:** `RdpEndpoint.kt` parses/formats `host[:port]` (default 3389 omitted in UI, bracketed IPv6 with custom port) and sets the drive label to `XyDesk` while keeping `sdcard` URI compatibility in `LibFreeRDP.java`.
6. **[CRIT] Soft-keyboard typing dropped digits (`0–9`), spaces, symbols, and non-composing letters.** `ImeCompositionBuffer.java:123` (`isPrintableImeTextEvent`) returned `true` whenever `(flags & KeyEvent.FLAG_SOFT_KEYBOARD) != 0` even when `hasComposingText == false`, causing `SessionView.sendKeyEvent` (`SessionView.java:709`) to swallow every printable `KeyEvent` sent via `InputConnection.sendKeyEvent`. In addition, `SessionSurfaceController.onText` sent characters as Unicode packets even when a HUD modifier (`Ctrl`, `Alt`, `Win`) was active, and `setImeVisible` used `SHOW_IMPLICIT` with a stale `isSoftInputActive()` guard. **Fix applied:** restricted `isPrintableImeTextEvent` to active non-digit/non-whitespace composition only, added `onKeyEventDispatched()` and `getTextBeforeCursor` in `SessionView`, switched `SessionView` to `TYPE_TEXT_VARIATION_VISIBLE_PASSWORD | TYPE_TEXT_FLAG_NO_SUGGESTIONS` for immediate character emission, routed ASCII characters as virtual key scancodes when HUD modifiers are active, and used explicit `WindowInsetsControllerCompat.show(Type.ime())`.
7. **[HIGH] Sidebar panel and modal overlays leaked focus, keystrokes, and drag gestures to the remote session.** `XyDeskSessionActivity.kt:300` routed `dispatchKeyEvent` to `controller.onKeyEvent` before `super.dispatchKeyEvent`, stealing keys from Compose `TextField`s (`Kustom WxH`, `Kirim teks`, `HudKeyPicker` search), while `.clickable` on `SessionPanel`'s scrim allowed drags to reach `trackpadGestures`/`SessionView` and Android Back opened the disconnect dialog instead of closing the active panel/modal. **Fix applied:** added `SessionSurfaceController.setOverlayActive` (hiding remote IME and bypassing `controller.onKeyEvent` while any overlay is open), consumed all background pointer gestures on scrims, hid the floating rail while the panel or layout mode is open, tidied `SessionPanel` with a pinned header/tabs and card sections, and wired hierarchical Back handling (`editing` -> `pickerOpen` -> `layoutJsonOpen` -> `textOpen` -> `panelOpen` -> `mappingMode` -> `confirmDisconnect`).
8. **[MED] Top-bar mapping controls, categorized key catalog, one-shot modifiers, HUD JSON export/import, and auto cellular low-bandwidth.** **Fix applied:** enhanced `HudMappingBanner` at the top of the screen with `+ Tambah`, `Reset`, and `Selesai` while keeping `mappingMode` active on add; expanded `HudKeyCatalog` into categorized tabs (`Kombinasi`, `F1 - F12`, `Single Key`, `Numpad`, `Huruf A-Z`, `Modifier`, `Mouse & Scroll`) with search in `HudKeyPicker`; added `HudAction.ONE_SHOT` (`Sekali pakai`); added `HudKey.exportLayoutJson` / `importLayoutJson` in `ButtonsTab`; and added `RdpOptions.resolveForActiveNetwork` to auto-enable `lowBandwidth` (`AVC420`) on cellular/metered links when `networkAutoDetect` is on.
9. **[CRIT] Clicking tabs or buttons inside `SessionPanel`, `HudKeyPicker`, or `HudKeyEditor` closed the panel/dialog.** `SessionControls.kt:896` and `SessionKeyLayer.kt:340,515` attached `consumeBackgroundPointer(onClose/onDismiss)` to the parent `Box` wrapping the foreground `Column`. Because `awaitFirstDown(requireUnconsumed = false)` on a parent `Box` receives every pointer event inside its children, tapping any tab or button inside `SessionPanel` triggered `onClose()`. **Fix applied:** separated the scrim backdrop into a sibling `Box` behind the foreground `Column` and attached `.pointerInput(Unit) {}` to the foreground `Column` in `SessionPanel`, `HudKeyPicker`, `HudKeyEditor`, and `XyOverlay`.
10. **[HIGH] Phone keyboard clipboard toolbar was hidden and clipboard sync still had manual sidebar buttons.** `SessionView.java:640` set `TYPE_TEXT_VARIATION_VISIBLE_PASSWORD`, causing Gboard/Samsung Keyboard to treat the session as a password field and hide the keyboard clipboard bar; meanwhile `InputTab` in `SessionControls.kt` still showed manual copy/send clipboard buttons and `XyDeskSession.kt:649` showed a `"Keyboard HP dibuka"` toast on every keyboard button tap. **Fix applied:** switched `SessionView.onCreateInputConnection` to `InputType.TYPE_CLASS_TEXT | InputType.TYPE_TEXT_FLAG_MULTI_LINE` so the phone keyboard clipboard toolbar stays active; added automatic phone-to-PC clipboard sync on `onPrimaryClipChanged`, `onWindowFocusChanged(true)`, `onResume`, and session connect (`syncPhoneClipboardToRemote`) plus automatic Gboard snippet sync (`onImeSnippetCommitted`); removed the manual clipboard buttons from `InputTab`; and removed the `"Keyboard HP dibuka"` notice.
11. **[HIGH] White hexagonal shape inside HUD control circles.** `HudKeyGlyph` (`SessionKeyLayer.kt:283`) used `XyIcons.ClickLeft`, `ClickRight`, and `ClickMiddle`—whose 6-vertex outline + solid white fill rendered as a white hexagon inside circular buttons—and `.shadow(elevation = 7.dp, shape = CircleShape)` on translucent HUD circles caused Android HWUI to draw a polygonal shadow cap inside the circle. **Fix applied:** rendered crisp text labels (`Kiri`, `Kanan`, `Tengah`) for mouse click circles, replaced the 6-vertex mouse icons in `XyIcons.kt` with clean stroke icons, and removed `.shadow(...)` from translucent HUD/rail circles.
12. **[MED] Dark UI text/system-bar inconsistency and missing confirmation/validation modals.** `XyDeskTheme.kt` did not provide `LocalContentColor` (defaulting to `Color.Black` on dark surfaces for any `Text` without an explicit `color`), did not sync Activity system bar appearance, and defaulted `AppPrefs.themeMode` to `0` (`FOLLOW_SYSTEM`). Destructive actions (delete device, kill active session, exit app, discard device edits, forget saved password, remove/clear trusted certificates, delete/reset/import HUD buttons, change remote resolution, cancel connection) lacked confirmation/validation dialogs. **Fix applied:** provided `LocalContentColor` and window system-bar sync in `XyDeskTheme.kt`, defaulted `AppPrefs.themeMode` to `1` (`DARK`), refined `DarkScheme` tokens, and added `XyDialog` confirmation/validation modals across all destructive and validation flows.
