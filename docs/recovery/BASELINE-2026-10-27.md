# Pembaruan baseline connection/native — 27 Oktober 2026

`ci/test_recovery_baseline.py` mengunci SHA-256 dari jalur koneksi/native yang
dipilih pemilik. Commit `f342d14` dengan sengaja mengubah tiga file yang dikunci,
sehingga hash di `docs/recovery/PROTECTED-CONNECTION-PATHS.json` perlu di-pin
ulang. Ini bukan pelemahan guard: semua file tetap dikunci, hanya nilainya yang
diperbarui bersama catatan alasannya. Preseden sama ada di commit `a45101a`.
