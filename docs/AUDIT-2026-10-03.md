# Audit XyDesk Remote — 2026-10-03

## Cakupan

Review fokus pada kualitas teks/resolusi sesi Windows, mode PC stream, dan rentang Android 7–16. Ditelusuri entry UI → preferensi → `SessionManager`/FreeRDP → tes → workflow Android. Issue koordinasi #8 dan XyDesk#34 sudah ditutup/arsip; perubahan ini tidak menyentuh kontrak audio lintas-repo.

## Temuan

1. **[HIGH] Mode Otomatis dapat memilih FHD di layar lanskap; mode PC tetap mengirim `/size`.** `SmartResolution.kt`, `SessionManager.kt`, `XyDeskSession.kt`, `SessionControls.kt`. Otomatis sebelumnya memilih sampai 1920×1080, sementara mode PC menyatakan resolusi monitor fisik dikunci tetapi URI awal masih bisa menambahkan ukuran virtual. Default kini dibatasi ke 1280×720; helper resolusi murni menjaga preset manual dan Follow, serta tidak meminta ukuran untuk PC Connect. Tes regresi ditambahkan. Visual hasil di perangkat/host nyata belum diverifikasi.
2. **[HIGH] Minimum API 29 menolak Android 7–9.** `release.properties`, `client/Android/Studio/build.gradle`. Keduanya kini memakai min API 24 (Android 7.0); split `armeabi-v7a` sudah tersedia. Konfigurasi mendukung rentang API 24+ secara deklaratif; install/run Android 7 dan Android 16 belum dibuktikan.
3. **[HIGH] Notifikasi memakai API 26 tanpa guard pada Android 7.0/7.1.** `XySessionService.kt`, `PrintNotificationHelper.java`. Pemanggilan pembuatan notification channel kini berhenti sebelum API 26; NotificationCompat tetap membangun notifikasi tanpa channel pada API lama.
4. **[HIGH] `SECURITY.md` sebelumnya memuat kebijakan FreeRDP seolah-olah kebijakan produk ini.** Diganti dengan alur pelaporan privat XyDesk Remote dalam Bahasa Indonesia dan Inggris; kerentanan upstream diarahkan juga ke FreeRDP.
5. **[MED] `PROGRESS.md` tertinggal setelah 2026-09-29.** Entri 2026-10-03 ditambahkan; hari-hari tanpa log tidak direka ulang.
6. **[MED] Workflow tidak menjalankan smoke test emulator API 24/36.** Build/JVM gate saja tidak membuktikan instalasi, service, notifikasi, atau RDP pada OS minimum/terbaru. Usulan matrix smoke terbatas API 24 dan 36 sebelum rilis.
7. **[MED] Catatan rilis store tertinggal.** `docs/STORE_DESCRIPTION.md` masih menyebut versi acuan 0.5.29 walau metadata repo 0.5.34. Perbarui saat menyiapkan rilis berikutnya; tidak diubah agar perubahan ini tidak mengarang nomor rilis.
8. **[MED] Batas waktu job debug 360 menit berisiko membiarkan runner berjalan terlalu lama.** Ukur durasi nyata sebelum menurunkan timeout agar tidak memotong build native yang sah.
9. **[LOW] Belum ada `THIRD_PARTY_NOTICES.md`.** Lisensi FreeRDP dan perubahan XyDesk ada di `XYDESK-REMOTE-NOTICE.md`; inventaris lisensi dependency Android tetap perlu dirapikan sebelum publikasi berikutnya.
10. **[LOW] Dokumen produk/kontributor belum lengkap.** `docs/PRD.md`, `docs/ROADMAP.md`, dan `CONTRIBUTING.md` tidak ada; README menjelaskan fungsi, tetapi hipotesis pendanaan/monetisasi belum terdokumentasi. Jangan mengarang model bisnis; dokumentasikan hanya jika memang jadi tujuan produk.

## Verifikasi dan risiko tersisa

- Review statis dan tes regresi sumber disiapkan; Gradle/native build, unit tests, APK install, dan uji visual tidak dijalankan di sandbox.
- GitHub Actions belum dijalankan dari branch ini. Status tetap **UNVERIFIED** sampai branch didorong melalui PR dan gate CI hijau.
- Resolusi 720p memperbesar elemen dibanding FHD pada layar kecil, tetapi bisa tetap terlihat lembut saat diskalakan. Jika teks masih pecah, validasi host DPI 100%, codec AVC444, skala surface, dan kebijakan server dengan screenshot yang sudah disamarkan.

## Acceptance test berikutnya

1. Android API 24: install APK armeabi-v7a, buka/tutup sesi, lalu uji jalur notifikasi sesi dan print tanpa notification channel.
2. Android API 36: jalankan sesi foreground, uji rotasi, notifikasi, dan resize RDP.
3. Windows host: Auto harus meminta 1280×720 di mode RDP; preset manual tetap berlaku; Follow tidak mengirim ukuran tetap; PC Connect tidak memaksa `/size`. Bandingkan teks pada host DPI 100% dan jaringan Wi-Fi.
