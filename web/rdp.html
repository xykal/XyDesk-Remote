🖥️ RDP dari Browser

Sambungkan sesi Remote Desktop ke PC Windows milikmu langsung dari browser — desktop, Android, sampai iOS (pasang sebagai PWA: Share → Add to Home Screen). Protokol RDP asli lewat gateway aman XyDesk — sama seperti di APK, lengkap dengan menu kontrol sesi (keyboard, mouse, layar penuh).

🔒 Kata sandi dikirim terenkripsi ke gateway (token HMAC + AES) dan tidak disimpan. Butuh host agent/guacd aktif di sisi gateway — lihat Host Agent. Gateway RDP berjalan di VPS XyDesk (konfigurasi pemilik).

iOS (iPhone/iPad): buka halaman ini di Safari → tombol Share → Add to Home Screen → aplikasi "XyDesk Remote" terpasang layaknya app native.
Android/Desktop: tombol Install muncul otomatis di navigasi bawah (Chrome/Edge) — atau menu browser → Install app.
Menu kontrol sesi: setelah tersambung, bar melayang di atas layar berisi keyboard, mode mouse, layar penuh, skala fit, dan putuskan sesi.
