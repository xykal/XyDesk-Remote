Windows Host Helper · Tahap Pengembangan (Experimental) · E2EE + Ultra-Low Latency

XyDesk Host Setup & Arsitektur Native PC

Fitur Koneksi PC (ID & Password) saat ini berada dalam Tahap Pengembangan (Experimental). Fokus utamanya adalah keamanan End-to-End Encryption (E2EE) serta pipeline Ultra-Low Latency khusus game FPS dan aplikasi grafis berat dengan penyesuaian GPU NVIDIA (NVENC), AMD (AMF), dan Intel (QuickSync).

Opsi 1 — Unduh Paket Native C++17 (`XyDeskRemoteHost.exe` + `xydesk_quic.dll` + `xydesk_host_core.dll`)

Paket lengkap Windows Host Agent 64-bit yang dibangun dengan C++17 Native: mencakup xydesk_quic.dll (Responder UDP QUIC v1 RFC 9000 port 4433), xydesk_host_core.dll (Deteksi DXGI GPU + Kebijakan AVC 4:4:4 + ClearType Font Smoothing + Multi-Session), XyDeskRemoteHost.exe, dan XyDeskHost-Setup.bat.

Opsi 2 — Jalankan 1 Baris Perintah di PowerShell (Admin)

Buka PowerShell (Run as Administrator) di PC Windows, lalu tempel perintah berikut:

irm https://rdp.xydesk.my.id/host.ps1 | iex

Arsitektur Native `XyDeskHost.exe` + `.dll` + QUIC (Roadmap Tahap Pengembangan)

  • Deteksi & Profil GPU Spesifik Vendor: Penyesuaian otomatis dan manual untuk NVIDIA GeForce/RTX (NVENC P1 Zero-B-Frame), AMD Radeon RX (AMF Ultra-Low Latency), Intel Arc/Iris Xe (QuickSync Low-Power), serta fallback CPU.
  • Transport QUIC Datagram & JNI Native (`.dll` / `.so`): Pengiriman frame video via QUIC Unreliable Datagrams bebas head-of-line blocking dengan tangkapan layar DXGI Desktop Duplication API zero-copy langsung dari VRAM GPU.
  • Input Mouse Relatif (`RawInput` / `SendInput`) untuk Game FPS: Mengatasi batasan kursor absolut RDP standar agar pergerakan kamera 360 derajat di game FPS tetap presisi.
  • Keamanan End-to-End (E2EE): Negosiasi TLS 1.3 ketat (`seclevel 2`), NLA, dan penyematan sidik jari sertifikat perangkat di Android Keystore tanpa server perantara yang dapat mengintip aliran layar.
