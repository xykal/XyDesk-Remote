Arsitektur Native `XyDeskHost.exe` + `.dll` + QUIC (Roadmap Tahap Pengembangan)

  • Deteksi & Profil GPU Spesifik Vendor: Penyesuaian otomatis dan manual untuk NVIDIA GeForce/RTX (NVENC P1 Zero-B-Frame), AMD Radeon RX (AMF Ultra-Low Latency), Intel Arc/Iris Xe (QuickSync Low-Power), serta fallback CPU.
  • Transport QUIC Datagram & JNI Native (`.dll` / `.so`): Pengiriman frame video via QUIC Unreliable Datagrams bebas head-of-line blocking dengan tangkapan layar DXGI Desktop Duplication API zero-copy langsung dari VRAM GPU.
  • Input Mouse Relatif (`RawInput` / `SendInput`) untuk Game FPS: Mengatasi batasan kursor absolut RDP standar agar pergerakan kamera 360 derajat di game FPS tetap presisi.
  • Keamanan End-to-End (E2EE): Negosiasi TLS 1.3 ketat (`seclevel 2`), NLA, dan penyematan sidik jari sertifikat perangkat di Android Keystore tanpa server perantara yang dapat mengintip aliran layar.
