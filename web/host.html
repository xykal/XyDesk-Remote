Windows Host Helper · Experimental · Opsional

XyDesk Host Agent untuk Windows

Host Agent Windows adalah opsi eksperimental untuk mode Koneksi PC. Untuk koneksi RDP standar, aplikasi Android tidak memerlukan Host Agent; gunakan alamat, port, dan akun Windows melalui mode RDP.

Perhatian sebelum instalasi: skrip setup mengubah pengaturan Remote Desktop dan Windows Firewall, serta meminta hak Administrator. Gunakan hanya pada PC yang kamu miliki atau kelola. Jangan membuka port RDP 3389 atau QUIC 4433 ke internet publik; gunakan VPN/Tailscale atau pembatasan alamat tepercaya, lalu tinjau aturan firewall sebelum melanjutkan.

Paket Windows x64 — Host Agent Eksperimental

Arsip rilis publik berisi XyDeskRemoteHost.exe, xydesk_quic.dll, dan xydesk_host_core.dll. Ini adalah komponen opsional; paket Windows ini bukan syarat untuk memakai koneksi RDP biasa. Lihat catatan rilis resmi dan checksum SHA-256 sebelum memasang.

Unduh dan tinjau skrip terlebih dahulu

Jangan jalankan skrip dari URL dengan | iex. Simpan file dan baca isinya terlebih dahulu. Bandingkan sumber PowerShell di repositori GitHub. File SHA256SUMS.txt rilis mencakup arsip/biner host, bukan skrip ini; hash yang dicetak di bawah hanya catatan lokal, bukan bukti autentisitas.

$script = "$env:TEMP\xydesk-host.ps1"; Invoke-WebRequest -UseBasicParsing "https://www.xydeskremote.biz.id/host.ps1" -OutFile $script; Get-FileHash $script -Algorithm SHA256; notepad $script

Roadmap — belum termasuk dalam rilis publik

Daftar berikut adalah sasaran pengembangan, bukan jaminan fitur yang tersedia di APK atau Host Agent publik saat ini. Validasi kompatibilitas, keamanan, dan performa masih diperlukan sebelum dianggap siap produksi.

  • Validasi pemakaian GPU: Pastikan host Windows benar-benar memilih encoder hardware yang didukung, ukur kualitas/performa per vendor, dan bedakan pengaturan kebijakan RDP dari encoding yang telah terbukti berjalan.
  • Aliran layar melalui QUIC: Arsip publik menyertakan komponen Host Agent/QUIC, tetapi keberadaan binary tidak membuktikan pipeline tangkap-layar-ke-video end-to-end, performa tertentu, atau ketiadaan relay.
  • Input mouse relatif untuk game: Uji integrasi `RawInput`/`SendInput` dan perilaku kursor pada host nyata sebelum memasarkan mode ini untuk game FPS.
  • Rencana keamanan: threat model, peninjauan independen, dan evaluasi perlindungan end-to-end masih diperlukan. Rilis publik saat ini tidak diklaim memiliki E2EE untuk mode Koneksi PC; NLA/TLS pada RDP standar bukan hal yang sama dengan E2EE.
