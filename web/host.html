XyDesk Host Agent (Native GUI) & Setup On-Mic RDP

Halaman ini menyediakan dua alat resmi: (1) XyDesk Host Agent (100% Native GUI tanpa terminal) untuk PC Windows pribadi dengan Clean ID & Password, Enkripsi E2EE, dan Virtual Device 120Hz; serta (2) File Setup On-Mic Mandiri untuk RDP Windows atau VPS Linux yang kamu beli/sewa sendiri di luar GitHub.

1. Setup On-Mic & Virtual Audio (Untuk RDP Beli Sendiri / Non-GitHub)

Jika kamu membeli RDP Windows atau VPS sendiri (di luar Buat RDP GitHub) dan ingin fitur On-Mic (Mikrofon HP ke dalam RDP untuk Discord / Game / Voice Chat) langsung bekerja lancar, unduh file .BAT di bawah atau jalankan perintah PowerShell 1-baris sebagai Administrator di dalam RDP:

powershell -ExecutionPolicy Bypass -Command "irm https://xydeskremote.biz.id/onmic.ps1 | iex"
Unduh File Setup On-Mic (.BAT) Unduh onmic.ps1

Untuk Linux Desktop RDP (Ubuntu/Debian XFCE4 + XRDP), jalankan: curl -fsSL https://xydeskremote.biz.id/onmic-linux.sh | sudo bash

2. Paket Windows x64 — XyDesk Host Agent (Native GUI Modern · 1 File .EXE)

Unduh XyDeskRemoteHost-Standalone.exe — antarmuka GUI Native penuh tanpa jendela terminal/CMD. Menampilkan Clean ID & Password (lengkap dengan tombol lihat/salin/acak password), Enkripsi E2EE AES-256-GCM + QUIC TLS 1.3 beserta sidik jari SHA-256, serta pengelola Virtual Display 120Hz & Virtual Microphone On-Mic. Lihat catatan rilis resmi dan checksum SHA-256.

Unduh Host Agent Native GUI — 1 File .exe (Standalone) Unduh Paket Lengkap (.ZIP) Unduh XyDeskHost-Setup.bat

3. Fitur Utama di Dashboard Native GUI Host Agent

  • Clean ID & Password: Menampilkan ID PC LAN (10 digit), ID Global Relay (XY...), Windows Username, dan Password Akses bersih yang dapat dilihat, disalin satu paket, atau diacak ulang kapan saja.
  • Enkripsi End-to-End & Sidik Jari Host: Perlindungan E2EE AES-256-GCM + QUIC v1 TLS 1.3 disertai Host Key Fingerprint SHA-256 unik per perangkat.
  • Virtual Device (Layar Virtual 120Hz & On-Mic Audio Bridge): Mengaktifkan 120FPS DWM + GPU H.264 AVC 4:4:4 Full-Chroma, membuka kunci fDisableAudioCapture=0 & Privacy Microphone Consent, serta menjembatani suara PC (WASAPI 24kHz) dan input mikrofon HP secara otomatis tanpa jendela terminal.

4. Unduh dan tinjau skrip PowerShell Host

Bandingkan sumber PowerShell di repositori GitHub.

$script = "$env:TEMP\xydesk-host.ps1"; Invoke-WebRequest -UseBasicParsing "https://www.xydeskremote.biz.id/host.ps1" -OutFile $script; Get-FileHash $script -Algorithm SHA256; notepad $script
