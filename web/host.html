Windows Host Agent · Native GUI v2.5 · Setup RDP Pribadi

XyDesk Host Agent (Native GUI)

Aplikasi desktop Windows 100% Native GUI tanpa jendela terminal/CMD. Menampilkan Clean ID & Password lengkap tombol lihat/salin/acak, Enkripsi E2EE AES-256-GCM + QUIC TLS 1.3 dengan Host Key Fingerprint SHA-256, serta Virtual Display 120Hz & On-Mic Audio Bridge untuk RDP pribadi, VPS, dan PC gaming.

Status: Rilis stabil v2.5 · Tersedia untuk Windows x64

1. Unduh Host Agent Windows x64 (Native GUI)

Unduh XyDeskRemoteHost-Standalone.exe — satu file .exe, antarmuka Native GUI penuh, tidak perlu terminal. Cocok untuk RDP Windows pribadi, VPS, dan cloud runner.

Unduh Host Agent (.exe Standalone) Paket Lengkap (.ZIP) Setup Script (.BAT)

Lihat catatan rilis resmi dan checksum SHA-256.

2. Fitur Dashboard Native GUI

Identitas Bersih Clean ID & Password ID PC LAN (10 digit), ID Global Relay (XY…), username Windows, dan password akses yang bisa dilihat, disalin, atau diacak kapan saja.
Keamanan E2EE AES-256-GCM + QUIC Enkripsi end-to-end dengan Host Key Fingerprint SHA-256 unik per perangkat. Tidak ada data yang bocong ke server pihak ketiga.
Performa Virtual Display 120Hz DWM 120FPS + GPU H.264 AVC 4:4:4 Full-Chroma, membuka kunci fDisableAudioCapture=0 dan Privacy Microphone Consent secara otomatis.
Audio On-Mic Audio Bridge Jembatani suara PC (WASAPI 24kHz) dan input mikrofon HP secara otomatis untuk Discord, game, dan voice chat tanpa jendela terminal.

3. Setup On-Mic & Virtual Audio (RDP Beli Sendiri / Non-GitHub)

Jika kamu membeli RDP Windows atau VPS sendiri di luar GitHub dan ingin fitur On-Mic (mikrofon HP ke dalam RDP) bekerja langsung, unduh file setup atau jalankan perintah PowerShell sebagai Administrator di dalam RDP:

powershell -ExecutionPolicy Bypass -Command "irm https://xydeskremote.biz.id/onmic.ps1 | iex"
Unduh File Setup On-Mic (.BAT) Unduh onmic.ps1

Untuk Linux Desktop RDP (Ubuntu/Debian XFCE4 + XRDP), jalankan: curl -fsSL https://xydeskremote.biz.id/onmic-linux.sh | sudo bash

4. Skrip PowerShell Host

Bandringkan sumber PowerShell di repositori GitHub sebelum dijalankan.

$script = "$env:TEMP\xydesk-host.ps1"; Invoke-WebRequest -UseBasicParsing "https://www.xydeskremote.biz.id/host.ps1" -OutFile $script; Get-FileHash $script -Algorithm SHA256; notepad $script
