XyDesk Host: kesiapan mic & game

Host generasi baru ditargetkan menjadi satu XyDeskRemoteHost.exe, tanpa varian Standalone atau DLL pendamping. Belum tersedia sebagai rilis publik. Halaman ini tidak menyatakan koneksi Direct sudah aman atau mic/game sudah berhasil diuji.

1. Status keamanan Direct

Transport UDP lama tidak menyediakan autentikasi dan enkripsi yang memadai. Pada source host baru, listener lama mati secara default. Pairing dan transport terautentikasi masih dikerjakan di kedua endpoint; belum siap untuk rilis. Jangan membuka UDP lama ke internet.

Versi publik sebelumnya adalah versi lama, bukan pengganti build aman yang masih dikerjakan. Lihat riwayat rilis resmi. Tidak ada tautan unduh untuk EXE baru sebelum benar-benar tersedia.

2. Pemeriksaan lokal mic & audio

Panel native membaca endpoint input/output aktif dan input komunikasi default Windows. Ini inventaris, bukan bukti suara HP sudah sampai ke game. Native AUDIN RDP, bridge audio dan stream Hub memiliki jalur yang berbeda.

  1. Periksa izin mikrofon Android dan pilihan mic pada sesi yang sedang aktif.
  2. Periksa Settings → Sound dan Privacy → Microphone di Windows, sesuai kebijakan pemilik/administrator.
  3. Untuk bridge, periksa output virtual terhubung ke input virtual yang dipilih game. Uji level suara dan matikan mic untuk memastikan capture benar-benar berhenti.

Installer On-Mic lama ditarik: tidak ada lagi perintah unduh-lalu-eksekusi, pembukaan firewall otomatis, perubahan password atau pemasangan driver tersembunyi. Driver bertanda tangan, lisensi, restart dan pengujian routing masih perlu diverifikasi. Panel bukan installer driver.

3. Pemeriksaan game & streaming

Panel menampilkan proses GTA/SA-MP/Roblox yang terlihat. Daftar server SA-MP atau proses yang muncul tidak membuktikan game berhasil dibuka. Jika macet, kumpulkan path/versi launcher, proses, Event Viewer dan crash log tanpa password/token.

Jika Roblox menolak VM/lingkungan tertentu, gunakan lingkungan yang didukung; tidak ada bypass atau penyamaran anti-cheat. FPS, encoder, frame, input dan suara harus diuji pada perangkat nyata.

4. Sebelum draft rilis

Wajib verifikasi pairing/transport kedua endpoint, single-EXE, APK bertanda tangan yang benar, mic/input saat putus-sambung dan jaringan lemah. Pemeriksaan syntax atau unit test bukan bukti runtime Windows. Draft rilis bukan publikasi otomatis.
