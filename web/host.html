XyDesk Host Setup untuk PC Windows

Gunakan XyDeskHost Setup di PC Windows Anda untuk menampilkan 10-Digit ID PC serta mengaktifkan enkoding hardware GPU (NVIDIA NVENC / AMD AMF / Intel QuickSync) H.264 AVC444 60 FPS dan jalur UDP 3389 secara otomatis.

Opsi 1 — Unduh File Installer Cepat (`XyDeskHost-Setup.bat`)

Unduh lalu klik dua kali berkas di bawah pada PC Windows Anda. Skrip akan otomatis meminta izin Administrator, menyalakan GPU Acceleration + RDP UDP, dan menampilkan ID PC (XXX-XXX-XXXX) Anda di layar.

Apa Saja yang Diaktifkan oleh XyDeskHost di PC?

  • ID PC 10-Digit Otomatis: Menghasilkan kode ID PC (mis. 323-223-5826) untuk dimasukkan langsung di menu Koneksi PC (ID & Password) pada aplikasi Android XyDesk Remote.
  • Akselerasi GPU Hardware (`bEnumerateHWBeforeSW = 1` & `AVCHardwareEncodePreferred = 1`): Memaksa sesi RDP merender desktop, aplikasi 3D, dan game menggunakan GPU diskrit PC.
  • Mode Warna Penuh `AVC444ModePreferred = 1` & `DWMFRAMEINTERVAL = 15`: Membuka batas kecepatan bingkai kompositor desktop Windows hingga 60 FPS dengan transport UDP 3389.
