Kebijakan Privasi — XyDesk Remote

Pembaruan terakhir: 29 September 2026 · Diterbitkan oleh XyVerse Technology Global

1. Penyimpanan Lokal & Kredensial

XyDesk Remote menghubungkan perangkat Android Anda secara langsung ke server Remote Desktop (RDP) milik Anda sendiri. Seluruh kata sandi yang disimpan dienkripsi menggunakan AES-256-GCM dengan kunci kriptografi non-exportable di dalam Android Keystore perangkat Anda.

2. Tidak Ada Pengumpulan Data Pihak Ketiga

Aplikasi ini tidak mengirimkan alamat host, kredensial, isi layar remote, maupun isi clipboard Anda ke server XyVerse Technology Global atau layanan analitik pihak ketiga.

3. Izin Perangkat

  • Jaringan (Internet): Diperlukan untuk koneksi TCP/UDP langsung ke host RDP dan paket Wake-on-LAN.
  • Mikrofon & Kamera (Opsional): Hanya digunakan apabila Anda mengaktifkan pengalihan kanal audio masuk atau kamera pada profil perangkat terkait.
  • Penyimpanan Lokal (Opsional): Hanya digunakan apabila Anda mengaktifkan fitur berbagi folder Drive 'XyDesk' dengan PC remote.
