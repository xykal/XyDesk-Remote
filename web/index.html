Unduh Paket Instalasi Android (APK)

Unduh APK resmi XyDesk Remote untuk perangkatmu. Tag rilis dan checksum mengikuti rilis GitHub terbaru. APK publik saat ini membutuhkan Android 6.0 (API 23) atau lebih baru.

RILIS PUBLIK · v1.1.20

Versi rilis: v1.1.20 adalah tag GitHub Release; versi aplikasi Android di dalam APK adalah 1.1.20.

Kompatibilitas: APK publik saat ini membutuhkan Android 6.0 (API 23) atau lebih baru.

Pilih ABI: arm64-v8a untuk kebanyakan HP modern, armeabi-v7a untuk perangkat ARM 32-bit, dan x86_64 untuk emulator/perangkat Android x86_64.
