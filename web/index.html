Mode Jendela Mengambang (PiP)

PiP Monitor

Pantau proses render, kompilasi, atau server Windows di jendela kecil mengambang saat membuka aplikasi lain di HP.

Pill Telemetri Live (FPS & RTT)

Live HUD

Indikator ringkas di pojok layar menampilkan FPS real-time, ping TCP RTT (ms), dan codec grafis aktif tanpa menghalangi kerja.

5 Preset Profil HUD Instan

HUD Profiles

Ganti tata letak tombol sekali ketuk: Standar, Coding/Terminal, Gaming/WASD, Office, atau Desain/Video.

Tombol Makro Multi-Langkah

Macro Key

Buat tombol bulat dengan label bebas yang otomatis mengetikkan perintah terminal/script dan menekan Enter.

Clipboard Teks & Gambar 2 Arah

Auto Sync

Salin teks atau screenshot di PC langsung masuk ke clipboard HP secara otomatis, dan salin di HP langsung terkirim ke PC.

Share-Sheet Langsung ke Drive PC

ACTION_SEND

Bagikan file atau foto dari aplikasi Android apa pun ke XyDesk Remote untuk langsung ditaruh di folder Drive 'XyDesk' PC.

Wake-on-LAN & Auto-Connect

UDP Magic Packet

Bangunkan PC dari kondisi Sleep/Shutdown lewat paket UDP 102-byte dan otomatis buka sesi RDP begitu port 3389 merespons.

Fisika Trackpad Presisi

Inertial + Edge

Kurva akselerasi pointer dinamis, inertial momentum scroll 2 jari, dan strip roda scroll 1 jari di tepi kanan layar.

Gamepad Fisik & Gyro Air-Mouse

Controller + Sensor

Gunakan stik Bluetooth/USB untuk menggerakkan kursor & klik, atau miringkan HP dengan sensor Gyro sebagai pointer laser.

Tirai Privasi & Kunci PC (Win+L)

Privacy Curtain

Gelapkan tampilan di layar HP saat ada orang di sekitar tanpa memutus sesi, atau kunci layar Windows dari jarak jauh.

SSH Jump-Host Command Helper

SSH Port Forward

Generator perintah tunnel `ssh -N -L` instan untuk menembus firewall/NAT kantor menuju host LAN internal.

Resolusi Dinamis & Skala DPI

DISP Channel

Ubah ukuran resolusi desktop Windows dan skala DPI (100%–200%) secara live di tengah sesi tanpa perlu reconnect.

Arsitektur Inti

Streaming, Latensi & Keamanan Kelas Enterprise

5 Profil Streaming Adaptif

GFX Pipeline

Pilih Otomatis, Latensi Ultra-Rendah (AVC420 + async pipeline), Seimbang, Visual Tajam (AVC444 32-bit + ClearType + Aero), atau Hemat Kuota (16-bit + kompresi level 2).

Async Update & Async Channels

Low Latency

Memisahkan antrean render frame (`+async-update`) dan pemrosesan kanal input/audio/clipboard (`+async-channels`) agar sentuhan tetap instan di jaringan seluler.

Hardening Keamanan Berlapis

Zero-Trust Ready

Pilihan protokol NLA/TLS/RDP, kebijakan OpenSSL TLS SecLevel (0/1/2), Restricted Admin anti pass-the-hash, proteksi layar FLAG_SECURE, kunci biometrik HP, dan auto-clear clipboard.
