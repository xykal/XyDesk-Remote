Tentang Founder & Tim

XyDesk Remote & Ekosistem XyRDP

Klien Remote Desktop (RDP) Android murni untuk mengakses dan mengontrol PC Windows maupun Cloud PC dari HP. Didirikan oleh xykal (Haekal Saputra) bersama tim XyVerse (XyVerse Technology Global) dan dikembangkan di Indonesia — berfokus pada koneksi remote desktop cepat, ringan, multi-ABI (termasuk ARM 32-bit), serta bebas fitur bloat non-RDP.

XY
xykal · Haekal Saputra
Founder & Lead Architect · XyDesk Remote & XyRDP
Founder: xykal (Haekal Saputra) Tim: XyVerse XyVerse Technology Global Indonesia

Merancang dan memimpin pengembangan XyDesk Remote serta penyedia Cloud PC XyRDP di Indonesia. Berfokus pada performa streaming RDP 60–120 FPS berbasis FreeRDP 3 JNI, dukungan perangkat 32-bit (armeabi-v7a) & 64-bit (arm64-v8a), audio dua arah (On-Mic), transfer file XyDesk:\Download, kontrol sentuh gamepad ala AetherSX2, dan integrasi modul native multi-bahasa (C, C++, C#, Rust, Kotlin, TypeScript).

Fokus Teknologi (Murni Koneksi RDP)

  • Remote Desktop Protocol (RDP) berbasis FreeRDP 3 JNI berlatensi rendah
  • Kontrol sentuh presisi, trackpad relatif, keyboard lengkap, & Gamepad Dual-Stick ala AetherSX2
  • Transfer file dua arah HP↔PC langsung ke drive XyDesk:\Download (kanal RDPDR)
  • Pengalihan audio stereo & mikrofon dua arah (On-Mic) di dalam sesi
  • Integrasi XyRDP Cloud (Aplikasi Esensial + WinRAR, Blender 3D 4.2 LTS, Roblox Studio, & XyMac OS Launcher)
  • Host Agent Windows opsional untuk koneksi langsung ber-ID
